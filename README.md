# Крестики-нолики (Tic-Tac-Toe)
Простая игра "Крестики-нолики", созданная с помощью React и Vite.
##  Запуск проекта
Перед началом работы убедитесь, что у вас установлен Node.js.  

### 1️⃣ Установка зависимостей:
npm install

### 2️⃣ Запуск в режиме разработки:
npm run dev

После этого проект будет доступен в браузере по адресу:  
➡ http://localhost:5173/ (порт может отличаться).  
При изменении кода страница автоматически обновляется.

### 3️⃣ Сборка проекта:
npm run build

## 🎮 Геймплей
- Два игрока по очереди ставят "X" и "O" на игровое поле.
- Побеждает тот, кто первым составит ряд из трёх одинаковых символов (по горизонтали, вертикали или диагонали).


## 🛠 Технологии
- React – компонентный подход и управление состоянием.
- Vite – быстрая сборка и удобная среда разработки.
- CSS-модули – стилизация компонентов.
